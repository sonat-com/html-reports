How this was measured

Method matters more than the headline, so here it is in full.

  • Six real support questions were asked against your live account on 30 July 2026.
  • Each question was run twice — once on GPT-4o-mini, once on GPT-5.6 Luna.
  • Both runs retrieved the identical 10 documents from your help center. Only the model changed.
  • Answers below are reproduced verbatim, with nothing edited, shortened or cherry-picked for tone.
Because retrieval was identical, the difference in these answers is not about what your documentation contains. The content was already there, and already found. The older model simply did not use it.

1  “How do I add a new manufacturer source?”

GPT-4o-mini — today no answer

I don't have enough information in the documentation to answer that completely.

GPT-5.6 Luna answered

To add a new Manufacturer Source: 1. In the left navigation, click Admin. 2. Go to Address Books and select Manufacturer Source List. 3. Click Create New Manufacturer Source. 4. Choose one of these options: - Add a Manufacturer Manually: Enter the manufacturer's information, add contacts, assign vendors and item types, review, and click Save Manufacturer. - Upload a File (.xls, .xlsx, .csv): Download and complete the provided template, upload it, select the valid entries, and click Add to Manufacturers List. - Import from Specsources Master List of Manufacturers: Select the manufacturers to add and click Add these Manufacturers to your Manufacturer Source List.

2  “How do I create a spec sheet?”

GPT-4o-mini — today no answer

I don't have enough information in the documentation to answer that completely.

GPT-5.6 Luna answered

Step 1: Go to the Dashboard and click on a Project. Step 2: Click the blue "Create New Spec" button in the upper-right corner. Step 3: Select the required Spec Type. Step 4: Select the required Item Type. Step 5: Enter an Item Name. Step 6: Enter the Item Price. A default value of "0" is provided if pricing is not required. Step 7: Click the Save icon. Before saving, you may also add a primary image, issue date, furnished-by and installed-by information, status color, issued-by and revised-by users, and lead time.

3  “How do I add more designers or users?” — both answered, but not equally

GPT-4o-mini — today incomplete

The program lets Designers / Users be added as long as the quantity of licenses purchased permits it. If the purchased amount is 2, then only 2 Designers / Users can be added. For more information, please refer to the following link: https://help.specsources.com/l…

States the license rule, never says how to add anyone, and ends on a truncated link. The reader still has to go and find the page themselves.

GPT-5.6 Luna complete

Designers or Users can be added as long as your organization has enough purchased licenses. The number of active licenses determines how many Designers/Users can be added. To add one: 1. Go to Dashboard. 2. In the left navigation, click Admin. 3. Go to User Management > Designers / External Users. 4. Click Create New Designer. 5. Enter the required name and email; phone is optional. 6. Select the office and assign a role. 7. Click Save. The user will receive an email to verify their address and create a password.
