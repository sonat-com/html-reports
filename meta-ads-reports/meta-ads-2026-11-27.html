Methodology note

This is a weekly executive digest built from aggregate account- and campaign-level totals pulled from the Meta Graph API (v21.0) for the reporting window (Nov 21–27, 2026) and the preceding equal-length window (Nov 14–20, 2026) for week-over-week comparison. It reports what changed, not a deep root-cause diagnosis. There is no day-by-day time series, no placement/audience/demographic breakdown, and no ad-set- or ad-level data behind these figures, so learning-phase status, marginal-CPA / Breakdown-Effect reasoning, auction-overlap, and relevance-ranking diagnosis are deliberately not attempted — the data to support them is not present. Audience size is reported as "Accounts Center accounts." All figures come directly from the API response; where a metric is undefined because there was no delivery, it is shown as "—" rather than estimated.
